# Bastián Olea Díaz — Portafolio

Portafolio personal enfocado en Data Science, análisis de datos y visualización.

Sitio estático (HTML, CSS y JavaScript sin dependencias) publicado con GitHub Pages en
https://bastian-olea-diaz.github.io/

## Estructura

- `index.html` — página de inicio
- `css/style.css` — estilos, animaciones y diseño adaptable (desktop, tablet y móvil)
- `js/main.js` — menú de navegación en móvil
- `comercio-ext-chile/` — página del proyecto Comercio exterior de Chile (`/comercio-ext-chile`) y sus figuras
- `css/proyecto.css` — estilos de las páginas de proyecto (relato largo con scroll)
- `js/relato.js` — apariciones al hacer scroll e índice lateral de las páginas de proyecto

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
python -m http.server 8000
```
